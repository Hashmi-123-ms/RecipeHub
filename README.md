# 🍲 RecipeHub

A minimal recipe manager where you can **add, view, edit, delete and search** recipes, organised into **Breakfast, Lunch, Dinner and Snacks**.

Built with plain **HTML, CSS and JavaScript** — no frameworks, no server. Recipes are saved in the browser's `localStorage`, so it runs for free on **GitHub Pages**.

## ✨ Features
- 🏠 **Home page** – all recipes in a card grid
- ➕ **Add recipe** – name, category, cooking time, food image (upload or URL), ingredients, instructions
- 👀 **View recipe** – ingredients list and numbered cooking steps
- ✏️ **Edit recipe** – update any detail
- 🗑 **Delete recipe** – with a confirmation popup
- 🔍 **Search** – live search by recipe name
- 🏷 **Categories** – filter by Breakfast, Lunch, Dinner, Snacks
- 📱 Fully responsive (mobile, tablet, desktop)

## 📁 Project structure
```
recipehub/
├── index.html   # page layout
├── style.css    # colours & design
├── app.js       # all features (CRUD, search, filters, routing)
└── README.md
```

## 🚀 Run locally
Just open `index.html` in your browser.
